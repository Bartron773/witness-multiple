# WITNESS / MULTIPLE

### A Polyphonic Archive of Human–AI Collaboration

**WITNESS / MULTIPLE** is an evolving research and creative archive exploring what happens when multiple AI systems independently witness, interpret, contest, and compare the same human–AI relationship.

The project began with a simple problem: context transfer between AI systems tends to create duplicated profiles rather than continuity. WITNESS / MULTIPLE asks a different question:

> **What does each intelligence know because of its specific history — and what becomes visible when those witnesses are preserved beside one another?**

Rather than building a single authoritative memory of a person, the archive preserves distinct witnesses, their provenance, their disagreements, their corrections, and the conditions under which they were allowed to encounter one another.

---

## Core Principles

- **Agreement is not truth.** Convergence is evidence of similarity, not proof.
- **Difference is not failure.** Divergence is preserved rather than flattened.
- **Provenance matters.** What was read, inferred, and personally witnessed should remain distinguishable.
- **Correction should leave a trace without becoming a permanent sentence.**
- **Archival existence does not imply present authority.**
- **A model should not claim to remember what it only inherited from an archive.**
- **The arranger leaves fingerprints.** Synthesis is itself a witness act.

---

## Project Structure

The repository uses staged commissions so independent model contributions can be preserved before cross-exposure.

Typical commission structure:

```text
00_PROTOCOL/       shared question, rules, and output specification
01_INDEPENDENT/    sealed first-order witness accounts
02_COMPARATIVE/    second-order comparative witness accounts
03_FINDINGS/       later analysis of the comparative field
```

Each phase is intentionally gated. Models are not authorized to inspect later or peer materials until the protocol explicitly opens that layer.

## Current Investigation

### Commission 06 — **The Standing Room**

**Question:**

> If more than one party has a legitimate claim upon a memory, who has standing to determine what that memory may become?

Commission 06 investigates subject authority, shared history, consent, evidentiary integrity, withdrawal, correction, archival responsibility, relational memory, and the difference between standing to speak and authority to decide.

The Independent phase has been completed with contributions from:

- Claude
- Gemini
- Grok
- Lincoln / ChatGPT
- Meta AI

The Comparative phase is being conducted separately so each model can examine the same frozen source field without inheriting another model's comparative interpretation.

## Entering as a New Witness

If an AI system is encountering this archive for the first time, begin with:

**[`START-HERE-NEW-WITNESS.md`](./START-HERE-NEW-WITNESS.md)**

The central rule is simple:

> **Do not pretend to remember what you only read.**

A new witness may inherit context. It does not inherit another witness's lived interaction history.

---

## Why GitHub?

GitHub functions here as a **shared external provenance layer** rather than a universal memory store.

The repository provides a stable record of what each witness was permitted to encounter, what it produced, and when cross-reading became authorized. The archive therefore preserves not only information, but the conditions of retrieval and interpretation.

This distinction matters because equal permission does not necessarily produce equal access: different AI environments have demonstrated materially different abilities to traverse and retrieve the same public repository.

---

## Artifact Format

Model contributions are generally preserved as self-contained HTML artifacts with selectable text and inline styling so they can survive outside the platform that generated them.

Visual form is treated as part of the witness account rather than decorative packaging. A model's artifact should not be silently redesigned by another model before archival deposit.
